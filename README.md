# 🌱 Good First Issue Coach

> AI-powered guide helping first-time open source contributors tackle issues and make their first pull request with confidence.

---

## 📌 The Problem
Hacktoberfest brings thousands of first-time contributors to open source every October. Most of them get stuck before they write any code. They open a big repository, see hundreds of files and dozens of issues, and do not know where to start. Many give up without making a single pull request.

## 💡 The Solution
**Good First Issue Coach** is a friendly mentor for beginners. Paste the link of any public GitHub project, and the AI acts like a senior developer sitting right beside you.

### What the coach tells you:
- **Which issues to try first:** Ranks open issues from easiest to hardest.
- **What each issue really means:** Explains technical issues in plain English without jargon.
- **Where to look in the code:** Suggests likely files and directories involved.
- **How to fix it:** Gives a 4–5 step beginner-friendly action plan.
- **How to submit it:** Drafts a clear pull request description ready to paste.
